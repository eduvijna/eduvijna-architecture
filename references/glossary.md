# Glossary

Agreed terminology for the EduVijna Enterprise Architecture Office repository.

| Term | Definition |
|------|------------|
| Architecture Office | The EduVijna Enterprise Architecture Office (EAO) responsible for architecture governance, standards stewardship, reviews, and related enterprise guidance in this repository. |
| Enterprise Architecture | The structured description of how EduVijna business, information, application, and technology concerns align and evolve under EAO governance. |
| Blueprint | An authorised engineering or delivery directive that defines how a specific work package or repository foundation is to be executed. |
| Specification | A precise, governed description of requirements or design constraints adopted under EAO process. |
| Architecture Review | A formal EAO-facilitated assessment of proposed architecture or related material before acceptance. |
| Program Charter | An authorised statement of programme purpose, scope, ownership, and success criteria for EAO-stewarded work. |
| Governance | The policies, processes, ownership, and controls that ensure architecture and engineering artefacts remain authoritative and reviewable. |
| Architecture Decision Record (ADR) | A durable record of a significant architecture decision, including context and consequences. |
| Decision Log | A chronological summary of approved architecture decisions; it is not a substitute for individual ADRs. |
| Reference | External or educational material curated to inform EAO practice; not an enterprise delivery asset. |
