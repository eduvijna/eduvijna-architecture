# References — Overview

## Purpose

Curate external reference material that informs EduVijna enterprise architecture, governance, and engineering practice.

## Scope

- External reference architectures
- Educational frameworks
- White papers
- Standards references
- Research references
- Glossary references

## Ownership

EduVijna Enterprise Architecture Office (EAO).

## Contents

- `glossary.md` — agreed terminology for this repository
- External and educational reference material authorised for EAO use

## Exclusions

- Enterprise assets, diagrams, and media owned as internal delivery artefacts
- Architecture models, standards, ADRs, and discovery reports
- Application source code and product documentation
- Unvetted or unofficial reference material
