# Assets — Overview

## Purpose

Provide a shared location for diagrams, templates, images, and other supporting media used by EAO artefacts across this repository.

## Scope

- Reusable visual and template assets referenced by architecture, discovery, roadmap, and blueprint documents
- Non-code supporting files that improve clarity of EAO communication
- Versioned media intentionally published for enterprise use

## Ownership

EduVijna Enterprise Architecture Office (EAO). Asset contributors must ensure licensing and confidentiality are appropriate for this repository.

## Contents

Bootstrap placeholder only (`OVERVIEW.md`). No diagrams, catalogues, or media packs are created in EBP-001.

## Exclusions

- Secrets, credentials, and production data extracts
- Large binary dumps without an owning artefact reference
- Application build artefacts and dependencies
- Architecture, standards, ADR, or discovery content that belongs in dedicated directories
