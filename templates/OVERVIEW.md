# Templates — Overview

## Purpose

Provide shared document standards and templates that keep EAO artefacts consistent and machine-friendly.

## Scope

- Document header and metadata standards
- Reusable Markdown templates for authorised artefact types
- Guidance that supports contribution quality without defining domain content

## Ownership

EduVijna Enterprise Architecture Office (EAO).

## Contents

- `document-header.md` — required front-matter standard for future Markdown documents

## Exclusions

- Completed architecture, standards, ADR, or discovery documents
- Implementation code and automation workflows
- External reference material (see `references/`)
