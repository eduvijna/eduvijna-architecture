# Meta — Overview

## Purpose

Provide machine-readable and human-readable metadata that describes this repository’s identity, taxonomy, and artefact inventory.

## Scope

- Repository manifest and lifecycle metadata
- Enterprise taxonomy used across EAO artefacts
- Artefact index schema for catalogue and discovery tooling

## Ownership

EduVijna Enterprise Architecture Office (EAO).

## Contents

- `repository-manifest.yaml` — repository identity and purpose
- `taxonomy.yaml` — enterprise taxonomy categories
- `artifact-index.yaml` — artefact index schema

## Exclusions

- Architecture content, standards, ADRs, and discovery reports
- Implementation code and CI workflow definitions
- Duplicate copies of artefacts stored in domain directories
